Features & matching

Useful Mat APIs

img.rows, img.cols, img.channels(), img.type() -> decode with CV_8UC3 etc.

img.at<uchar>(y,x) for single-channel; img.at<cv::Vec3b>(y,x) for 3-channel 8-bit

img.ptr<uchar>(row) for raw pointer iteration (faster in loops)

img.clone() for deep copy; cv::Mat m2 = m1; is a shallow copy (header only — they share data).

Types

CV_<bitdepth>U|S|F C<num_channels> e.g. CV_8UC3, CV_32FC1.

- Region of Interest ROI

>>cv::Mat cropped = img(roi); // shallow view (same data buffer shared new headers)

- Acessing pixels
# using .at<> slower but safer
>>cv::Mat gray = cv:: imread("data/test.jpg", cv::IMREAD_GRAYSCALE);

>>gray.at<unchar>(10,20) = 255; // setting pixel to white

- type codes
std::string type2str(int type) {
    std::string r;
    uchar depth = type & CV_MAT_DEPTH_MASK;
    uchar chans = 1 + (type >> CV_CN_SHIFT);
    switch ( depth ) {
        case CV_8U:  r = "8U"; break;
        case CV_8S:  r = "8S"; break;
        case CV_16U: r = "16U"; break;
        case CV_16S: r = "16S"; break;
        case CV_32S: r = "32S"; break;
        case CV_32F: r = "32F"; break;
        case CV_64F: r = "64F"; break;
        default:     r = "User"; break;
    }
    r += "C"; r += std::to_string(chans);
    return r;
}

- inverting colors
#using .at<>
for (int y = 0; y < img.rows; y++) {
    for (int x = 0; x < img.cols; x++) {
        cv::Vec3b &pixel = img.at<cv::Vec3b>(y,x);
        pixel[0] = 255 - pixel[0]; // invert B
        pixel[1] = 255 - pixel[1]; // invert G
        pixel[2] = 255 - pixel[2]; // invert R
    }
}

#using .ptr<> faster and works even if not continuous
for (int y = 0; y < img.rows; y++) {
    uchar* rowPtr = img.ptr<uchar>(y);
    for (int x = 0; x < img.cols * img.channels (); x++) {
        rowPtr[x] = 255 - rowPtr[x];
    }
}

// Image I/O ###############################
cv::imread(path, flag)
- flags: how to interpret image:
cv::IMREAD_COLOR (default): 3-channel BGR (8UC3).
cv::IMREAD_GRAYSCALE: 1-channel gray (8UC1).
cv::IMREAD_UNCHANGED: keep alpha if present (e.g., PNG RGBA → 8UC4).
cv::IMREAD_REDUCED_COLOR_2 / _4 / _8: downsample while loading

cv::imwrite("output.png", img);
# Supports many formats: PNG, JPG, TIFF, BMP, etc.

- compressing the output
std::vector<int> params = {cv::IMWRITEJPEGQUALITY, 90} // 0-100
cv::imwrite("out.jpg", img, params);
